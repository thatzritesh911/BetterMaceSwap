What it does

Every PvP tool
you actually need

Precision-engineered features for competitive Minecraft PvP — each one configurable, each one fast. Tap a feature to see what it does.

💥

Stun Slam

Automated stun slam timing with configurable tick windows. Fires at exactly the right moment based on mace wind-up state.

🎯

Aim Assist

Smooth, constant-speed yaw correction. No jitter, no snap — configurable aimSpeed with clamped step math to feel natural.

🖱️

Triggerbot

Auto-attacks when your crosshair lands on a player. Ray-cast based targeting with range and delay configuration.

🧪

Pearl Catch

State machine driven ender pearl catch automation. Tracks projectile trajectory and triggers pickup at optimal distance.

💨

Wind Charge Automation

Automates wind charge timing relative to mace swing state. Boosts burst damage windows without input lag.

🔄

Lunge Swap

Auto-swaps between mace and other tools during lunge phase. Fully configurable slot index and swap threshold.

🛡️

Auto Chestplate

Automatically equips chestplate post-swap based on combat state detection. No manual slot management mid-fight.

⚙️

Mod Menu Config GUI

Full Mod Menu integration. Open the config screen straight from the mods list, toggle every feature there — zero command typing mid-game.

mod menu
💬

Clickable Chat Toggles

/bms status prints every feature grouped by category — combat, aim, pearl, stunslam, misc — as clickable ON/OFF toggles. No GUI needed.

FAQ

Common questions

Things people actually ask about BetterMaceSwap.

Is this client-side only?
Yes, it runs entirely on your client — no server-side install needed. That said, this isn't a hacking or cheat client and isn't meant to be used to gain an unfair edge on public servers. It's built for practicing PvP on your own personal server or with friends who know you're using it. Use it on servers where automation tools aren't allowed and you risk getting banned — that's on you, not on us.
Does it conflict with performance or shader mods?
Most performance mods run fine alongside it. Some shader mods have caused memory-related stuttering for a few users — if you notice lag spikes, try running without shaders first to rule it out.
How do I open the config screen?
Open it from Mod Menu in your mods list, or use /bms status in chat to get clickable toggles right there. Every toggle is mirrored between the two.
What Minecraft versions are supported?
Supported on 1.21.10, 1.21.11, 26.1, and 26.2. The 1.21.10/1.21.11 builds use Yarn mappings; 26.1 and 26.2 use Mojang mappings. Check the CurseForge page for the exact build matching your version.
Is it free? Will it stay free?
Yes, completely free — and it'll never be paywalled.
Who made this?
BetterMaceSwap is built solo by a self-taught developer from Pune, India — started as a personal PvP tool and grew to 27,500+ downloads by word of mouth.
